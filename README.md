# Ajnur Begovic — Frontend Portfolio

Responsive portfolio built with semantic HTML, custom CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your real professional email.
- Replace `YOUR_GITHUB_USERNAME` with your GitHub username.
- Review the skills section and only keep skills you can explain honestly.
- Test every demo link on desktop and mobile.

## Projects
1. SupportDesk — IT support ticket tracker.
2. TradeLog — trading journal with R-multiple summaries.
3. TaskFlow — task manager with filters and browser storage.

These are frontend learning projects. They use local browser storage and do not have a backend, authentication, or production data. Do not describe them as production-ready.
